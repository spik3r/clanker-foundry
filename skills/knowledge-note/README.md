# knowledge-note

Creates and maintains concise, connected notes in an Obsidian vault or another personal
knowledge base. It follows the target vault's existing structure, metadata, links, and
index conventions so notes remain findable rather than becoming isolated documents.

## When to use

Use it to capture or update a topic, system, investigation, convention, meeting, or
reference note in a knowledge base. It may edit only the named vault.

Do not use it for standalone documents, durable architecture decisions, or task
handoffs; use `adr`, `checkpoint`, or `context-offload` instead.

## Output

**Summary**, **Evidence**, **Changes**, **Risks**, and a **Next action** when needed.
It reports the note and index files created or updated.
