# Backlog maintenance

Reconcile the backlog with implementation and validation evidence. The
[skill](SKILL.md) identifies stale or duplicate work, records blockers and closes
completed tasks while preserving their IDs and links.

```text
Use backlog-maintenance to review this queue; propose changes without editing.
Use backlog-maintenance to close the verified tasks and link superseded records.
```

Review requests stay read-only. Requested upkeep edits only the agreed task records;
it does not implement backlog items or take over active claims. No other skill is
required. See the [adoption guide](../../docs/task-workflows.md) for the wider workflow.
