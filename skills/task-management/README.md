# Task management

Create and maintain actionable tasks without changing the project's tracker.
Use it for agreed work, task progress and evidence-based closeout. It writes task
records within the requested scope; it does not implement the task or publish work
as a side effect.

```text
Use task-management to turn this agreed change into a task in our existing backlog.
Use task-management to update this task with the validation and remaining dependency.
```

The [skill](SKILL.md) includes a [file-backed template](templates/task.md), suggested
states for projects without a lifecycle, and guidance for dependencies and ownership.
It works without other skills. See the [adoption guide](../../docs/task-workflows.md)
for choosing a task store and connecting tasks to handoffs.
