# Foundry templates

Copy an example into its destination, replace its prompts and remove the
sections you do not need. Start with the smallest template that suits the reader.

| Need | Start with |
| --- | --- |
| Submit or clarify an authorised private security report | [Disclosure report](bug-bounty/disclosure-report.md) or [triage follow-up](bug-bounty/triage-follow-up.md) |
| Report delivery progress in Word, Google Docs or Markdown | [Progress reports](progress-report/README.md) |
| Write a README, quickstart, requirements, troubleshooting guide or release note | [Documentation building blocks](docs/README.md) |
| Set up a repository | [Project README](project/project-readme.md) and [new project checklist](project/new-project-checklist.md) |
| Record an architecture decision or review | [ADR](adr/adr-template.md) or [architecture review](architecture-review/architecture-review-template.md) |
| Hand off implementation or open a pull request | [Model implementation handoff](model-driven/implementation-handoff.md) or [pull request](pr/pull_request_template.md) |
| Generate a diagram from a model | [Diagram starters](diagrams/README.md) |

The security templates are blank reporting aids. Submit completed reports only
through the relevant authorised private channel, not to a public repository.
