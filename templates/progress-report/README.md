# Progress report templates

- **Microsoft Word:** download [the editable Word template](progress-report.docx),
  save a copy and replace the bracketed prompts.
- **Google Docs:** upload the same Word template to Drive, open it in Google Docs
  and choose **File → Save as Google Docs**. Keep a clean master and use
  **File → Make a copy** for each new report.
- **Markdown:** copy [the Markdown template](progress-report.md) for a pull
  request, issue, wiki or plain-text update.

Use one report per period. Lead with a short status summary, separate verified
outcomes from next work, and put an owner and due date beside each ask. Replace
unused prompts with “None” or omit the section if the audience does not need it.
