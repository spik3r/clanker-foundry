# Solid compiler and render check

From the repository root, with Node 24 or later and the diagram module's Go
toolchain installed:

```sh
npm ci --prefix modeling/diagram/verify/solid --ignore-scripts --no-fund --no-audit
npm test --prefix modeling/diagram/verify/solid
```

The diagram CI job runs both commands and fails if compilation, rendering or
an assertion fails. It does not skip when dependencies are missing. This does
not configure branch protection.

The test builds the current `diagramgen`, generates new components from public
example models, compiles JSX with the pinned Solid preset and renders through
Solid's server renderer. Parsed HTML is checked against literal stats, table
cells, chart marks, titles and host classes. Hostile model text must survive as
text and attribute values without creating elements or event handlers. Negative
controls reject invalid JSX and an altered stat value. Temporary output stays
inside this package for module resolution and is removed after the tests.

These are server-rendered checks. They do not exercise a browser DOM, hydration,
CSS layout, host integration or human visual acceptance. The separate Go tests
still check generated bytes and chart geometry.
