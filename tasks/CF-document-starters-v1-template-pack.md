# Reusable document starters

## Implementation claim

Byte owns an additive, copy-first document starter pack: responsible disclosure
and triage templates in Markdown, a progress report in Markdown and Word that
can be copied in Google Docs, and reusable Markdown blocks for READMEs,
quickstarts, requirements, troubleshooting and release notes. Link the pack
from the main README and retain the existing project, ADR and diagram templates.
No report submission, real finding data, deployment, or generator changes.
