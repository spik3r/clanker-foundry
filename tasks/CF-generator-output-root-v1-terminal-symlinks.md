# Reject output-root symlinks with terminal path syntax

## Implementation claim

Owner: Codex output-root maintenance contributor, assigned by the coordinating
session under the owner's authorized maintenance window. Base: main at
`9371406`, after the filter Unicode fix. The coordinator reviewed live claims
and queued this task before the diagram layout repair. PR #144 edits only the
JSON profile/schema guidance and does not overlap this implementation.

All five registered generators refuse `check MODEL link` with exit 3 when link
is a symlink to valid generated output, but accept `link/` and `link/.` with
exit 0. The operating system follows the terminal symlink before Lstat sees it.
The contract requires the output root to be a real directory. The shared
conformance harness tests symlinks inside output but omits symlinked roots.

Remove only terminal separators and dot components before checking the root.
Preserve interior path components, including `..` across symlinked parents,
and preserve roots, drive/UNC volumes, a lone dot and an empty input. Do not
introduce an ancestor-symlink ban. Apply the same bounded procedure in each
independent generator module. No generated bytes or generator versions change.
