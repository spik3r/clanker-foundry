# A fresh builder through preparation and admission

This trial used the existing preparer to give a fresh agent the frozen Go
exercise, reviewed its candidate, checked the complete source frontier, then
separately authorized compilation and tests. Both executed binaries passed all
30 literal cases and three isolation tests. The race binary reported no races.
Three separate admission-only copies were blocked as expected.

This is one fictional local observation, not a maintained implementation,
product acceptance or a claim about agent reliability. The candidate and
executables remain private. Q_use, visual approval and real-use acceptance stay
open. The [earlier pilot](../evidence.md), including its C06 read-scope violation,
is unchanged; this trial does not replace that account.

## What this trial adds

The [preparer walkthrough](../preparation.md) ends with a proposed draft. The
[admission checker](../../../modeling/lifecycle/builderadmission/README.md) can
match opaque bytes without establishing that an implementation works. This run
used a new agent-written candidate and the unchanged independent Go expectations
together, through distinct source, build and execution gates.

The builder initially received only named input reads and permission to create
candidate.go. It did not compile, format or execute code. The coordinator and
separate reviewer read the entire exact source before admission and build-only
authority. The coordinator then reviewed each produced binary before granting
its execution. Test products, caches and temporary files stayed outside exercise,
which retained exactly six regular files throughout.

The copied draft proposed a binary inside exercise. The new trusted receiving
prompt explicitly superseded that proposal with external products. No pinned
packet, old source, acceptance literal, preparer or admission implementation was
changed to make the run pass. The retained worker call history was audited against
the grants; it is attributed history, not an operating-system audit.

## Reuse needs fresh authority

Do not execute this record as a script or treat its historical approvals as a
current grant. A future coordinator must bind current instructions, ownership,
exact inputs, read/edit scope, toolchain resources, source review and each later
build/run step again. Installing the skill pack does not install this example or
its tools. Source hashes and successful tests do not establish correct
requirements, independent human approval, sandbox enforcement or deployment
permission. No worker launcher or automatic execution wrapper was added.
